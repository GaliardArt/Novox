# NOVOX 1.1.0 — Modern UI Redesign

## Highlights
- Reorganized the application into Play, MIDI, Audio, and Presets tabs.
- Introduced a dark graphite interface with coral accent styling using native JUCE controls.
- Dedicated Play screen for detected pitch, frequency, confidence, Pitch Bend feedback, and vocal percussion activity.
- Separated MIDI routing and General MIDI percussion mapping from audio tuning.
- Consolidated input gain, pitch sensitivity, smoothing, and runtime diagnostics in the Audio tab.
- Consolidated local preset management in the Presets tab.

## Compatibility
This release changes the presentation and placement of existing controls. Audio processing, pitch detection, MIDI routing, percussion detection, local settings, and preset storage behavior are retained.
